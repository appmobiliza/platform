## Configuração do TypeScript

O pacote `@mobiliza/typescript-config` reúne os presets de TypeScript compartilhados pelo monorepo.

### Responsabilidades

* padronizar opções de compilação
* manter presets por tipo de projeto
* reduzir divergências entre apps e packages

### Presets esperados

* base
* Expo / mobile
* Next.js / web
* biblioteca de React

### Observação

Use estes presets como base para novos projetos internos do monorepo em vez de criar configurações isoladas.
